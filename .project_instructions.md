# MarketCommand Website

## Overview
Marketing landing page for MarketCommand mobile app - a two-sided marketplace for street fairs, farmers markets, and county fairs connecting organizers and vendors.

## Visual Style
- **Primary Colors:** Teal (#0D9488 range) and Orange (#F97316 range)
- **Fonts:** DM Sans (body), Plus Jakarta Sans (display/headings), JetBrains Mono (numbers)
- **Theme:** Light mode only (defaultTheme="light")
- **Logo:** Text-based "Market" (teal) + "Command" (orange) with MapPin icon
- **Design:** Clean, modern, conversion-focused SaaS marketing style

## Pricing Model
- Vendors: FREE
- Organizers: $59/month flat fee
- Event fee: $2.50/day/vendor

## Page Structure
Single-page landing with sections:
1. Sticky header with nav links + CTA
2. Hero with parallax street fair image
3. Social proof stats strip (animated counters)
4. Features grid (6 cards)
5. Booth mapping showcase (image + feature list)
6. Organizers section (image + benefits grid)
7. Vendors section (image + benefits grid)
8. Pricing cards (2 plans)
9. Document management showcase
10. Roadmap (3 phases: Available Now, Coming Soon, On the Horizon)
11. CTA section (dual audience buttons)
12. Minimal footer

## Technical Patterns
- All interactive content in single client component: `components/landing/landing-page.tsx`
- Page.tsx is server component that imports LandingPage
- Uses framer-motion for animations, react-intersection-observer for scroll triggers
- CDN-hosted images (abacus.ai CDN)
- No database needed (static marketing page)
